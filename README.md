# Parcel-PT Privacy Policy

Public privacy policy for the [Parcel-PT](https://github.com/klesiossss/parcel-pt) Shopify app, hosted on GitHub Pages.

## Live URL

After Pages is enabled:

**https://klesiossss.github.io/parcel-pt-privacy/privacy-policy.html**

Use this URL in the Shopify Partner Dashboard → App setup → Privacy policy URL.

The site root also redirects to the same page:

**https://klesiossss.github.io/parcel-pt-privacy/**

## Update the policy

1. Edit `index.html`
2. Commit and push to `main`
3. GitHub Pages redeploys automatically (usually within a minute)

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
# visit http://localhost:8080
```
